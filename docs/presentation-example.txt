🧀 Présentation PowerPoint – TP Fromagerie DIGICHEES
🎯 Slide 1 – Titre

Titre : Projet de refonte du SI – Fromagerie DIGICHEES

Sous-titre : Développement d’une API avec FastAPI, SQLAlchemy & MySQL

Auteur : Florian Arnau

📝 Slide 2 – Contexte

Application initiale sous Microsoft Access (2000)

Problèmes : instabilité, obsolescence, faible évolutivité

Besoin de refonte pour moderniser et sécuriser l’outil

🧑‍💻 Slide 3 – Objectifs du projet

Créer une API moderne en FastAPI

Migrer la base de données vers MySQL

Sécuriser et structurer le code

Intégrer les rôles utilisateurs (Admin, OP-colis, OP-stock)

Améliorer l’ergonomie et la maintenance

🗂 Slide 4 – Stack technique

Backend : Python 3.13, FastAPI

BDD : MySQL + SQLAlchemy (ORM)

Serveur : Uvicorn

Gestion de versions : Git / GitHub

Outils : VSCode, phpMyAdmin (Herd)

🏗 Slide 5 – Modélisation BDD

Tables principales :

t_client, t_commune, t_commande, t_objet, t_conditionnement

Relations via Foreign Keys (ex : villecli_id → t_communes.id)

Diagramme simplifié (ajoute un schéma si tu veux)

Administration des communes et départements

📦 Slide 7 – Fonctionnalités OP-colis

Gestion des clients & commandes
